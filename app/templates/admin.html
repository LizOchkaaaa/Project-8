Обязательные правила

  • Нужны отчёты всех пяти сканеров, даже если API выключен.
  • Секреты, критические замечания и неизвестная серьёзность всегда блокируют допуск.
  • Ошибка, таймаут или отсутствующий отчёт означают отказ.

Эти настройки действуют для веб-загрузки, API инструментов и MCP. Выпуск в CI использует версионируемую .security/policy.yml; админ-панель её не изменяет.

Окружение обработки

Лимиты получения отчётов. Системные переменные и команды здесь не изменяются.

До 8 МиБ на отчёт и один полный анализ одновременно. Системный DNS и вычисления Python нельзя принудительно прервать точно по этому бюджету. Стенд рассчитан на один процесс.

Внешний MCP-клиент вызывает тот же анализ, что и веб-интерфейс.

Проверяем…

Streamable HTTP, протокол 2025-11-25. Доступны три инструмента:

get_policy
Прочитать действующую policy.
analyze_reports
Разобрать переданные JSON-отчёты.
run_tools
Получить отчёты настроенных API и разобрать их.

Пример параметров подключения

Для включения задайте отдельный PROJECT8_MCP_TOKEN в окружении сервера и перезапустите приложение. Токен не показывается в панели. Поддерживаются локальные HTTP-клиенты с настраиваемым Authorization; OAuth, stdio и доступ через публичный прокси не реализованы.
