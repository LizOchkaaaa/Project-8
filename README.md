# Тема 8. Безопасная сборка и выпуск приложения

### Проблема
Приложение может быть опубликовано с уязвимостями или опасными настройками.

### Основное задание
1. Разработать автоматизированный процесс проверки, сборки
и развертывания небольшого приложения.
2. Реализовать не менее трех видов проверок безопасности и
запретить выпуск при обнаружении критических проблем.
3. Обосновать состав и последовательность проверок. 
4. Провести тесты: добавить учебную ошибку, показать отказ в выпуске и успешное
прохождение после исправления.

### Дополнительное задание – ИИ-агент
Разработать помощника, который получает отчеты неуспешных проверок, объединяет связанные замечания и предлагает
разработчику порядок исправления ошибок.
